Access and safety

A page is code a model wrote, running in Shellby. It starts with nothing but its own data, and gets each door opened by you, in plain words.

One list, read the same way everywhere. The access sheet says what each entry lets the page do, and the same list appears on first run, when a version asks for more, in Settings, and when a page tries something it wasn't given. Glass means allowed, coral means it's waiting on you, amber means something was refused, and red is kept for the one switch that stops everything.
