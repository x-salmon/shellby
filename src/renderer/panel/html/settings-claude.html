Billing

If an API key or another provider (Bedrock, Vertex, Foundry) is set on this PC, Claude Code bills that, per token, instead of your Pro or Max plan. Turn this on and Shellby leaves them out, so every conversation runs on your plan. Applies to new conversations.

Conversations can hand each other work on each project's task board, and start a helper for a task: in its own copy, in the same mode (Smart at most), at most three at once, never at your usage limit. They can also see the other conversations open in the same project, read what was said there and pass one a brief. Never another project's. Applies to new conversations.

When one conversation passes work to another, a card shows you the brief first and nothing is sent until you say so.

Claude gets a short note about Shellby and can make him talk, celebrate or dress up. The note never changes, so Claude Code caches it and it costs very little of your plan. When your usage passes 80%, Claude is told so it can keep things lean. Offers show up as cards and nothing happens unless you tap them. Changes apply to new conversations.

Permission cards and the Working bar say what a step does ("Run your tests in its own copy of the repo") and point out deletes, files outside the project, installs and anything that goes online. The command itself is still shown. Worked out by Shellby from the step itself, so it costs no usage.

A conversation of 200K tokens or more that sits quiet for 54 minutes gets compacted just before its prompt cache runs out. That way your next message doesn't send the whole conversation again at full price. It uses some of your plan while you're away, even on a tab you never go back to. A project whose Claude Code settings say "idleCompaction": false is left alone.

How much can Shellby do?

Autonomous mode skips every permission check. Shellby and its helper agents can edit, run or delete anything your Windows account can, without asking. That includes running scripts it writes for itself. Use it only for tasks you'd trust to an unsupervised script.

Local model

The drafts you pick below go to Ollama or LM Studio on this PC before Claude, so they don't use your plan. If it isn't running, takes too long or gets one wrong, Claude writes it as usual. Nothing leaves this PC, but whatever answers at this address gets what a draft is about, including your projects' folder names.

What it writes first

When Claude declines a question, a card under it offers to ask this model instead. Only your question goes, only when you press the button, and the answer is shown as the local model's, apart from Claude's conversation. Pick a model you trust with what you ask: an uncensored one answers anything, accurately or not.

Claude Code does the work as usual, with every tool, but thinks with this model instead of Claude, so nothing is spent from your plan and nothing leaves this PC. Needs Ollama 0.14 or LM Studio 0.4.1 or newer, and a model made for coding and tool use with a long context (32K tokens or more; Ollama starts most models with less). Each conversation keeps what it started on for good, reopened or branched later too, and a local one can't be sent to a terminal. Smaller models make more mistakes: watch what they change.
