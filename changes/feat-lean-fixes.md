### New
- **The Lean tab says what every turn carries, item by item.** The output style, each CLAUDE.md and rule that loads, each plugin, your skills' listings, MCP servers and the hooks that add text, each with its size (an estimate, and it says what it rests on) and its share of what a message carries before your words. Under it, what could go: an output style switched off from here (asked first, undoable), an idle plugin turned off, or a section of your global CLAUDE.md that only one project uses, pointed out for you to move. The opened footer under a reply shows the one-liner: "setup ~14k/turn".
- **One-tap fixes for repeated big reads and loud commands.** A file Claude keeps reading gets a drafted line for CLAUDE.md saying what it holds, written from the file's own first lines, no model call. A lockfile or build output it reads whole gets a deny rule for the project's `.claude/settings.json`. A command whose output fills the context gets a quieter way to run it. Each shows the diff first; Apply asks in the confirm window, writes only if the file still reads as shown, and Undo on the row puts it back.
