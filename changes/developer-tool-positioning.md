### Changed

- **Your tools from day one.** If you already use Claude Code on this PC, History, Projects, Notes, Health, the Toolbox and Automate are on the bar from the start. His own screens (trophies, finds, the tank) still open as you two go.
- **A first run that leads with Claude Code.** **Claude Code + crab** comes first, then Work mode, Claude Code on another computer, and Just the crab. When Claude Code is already installed, Work mode says it's made for you, but it's still your pick.

### Removed

- **Snacks and naps.** He no longer gets peckish, sandy, sleepy or mopey, and Feed, Rinse and Tuck in are gone from his menu and the Us page, along with their setting and five trophies. There's nothing to look after now, and none of the XP, levels or bond you've earned goes anywhere.
