### New
- **Haiku for the quick ones, asked first.** Send a short question or a small named change into a conversation on Opus and a card appears in the chat before Claude starts: what a message like it usually takes of your 5-hour window on Opus and on Haiku, with Use Haiku for this one, Keep Opus, or Always for questions like this. Nothing switches unless you pick, and a short countdown keeps the model you're on. "This one" runs just that turn on Haiku and the tab goes back to its own model; "Always" sends that kind of message to Haiku by itself from then on, with a note on each turn and Undo. The card backs off after you keep Opus twice in a row, never asks for /commands, Ultracode turns, batched messages or conversations already on Sonnet or Haiku, and Settings → Limits turns it off.
- **A nudge under a repeated big read.** When Claude reads a big file whole that it has read in three or more conversations this week, a card lands under that step while the turn carries on: how often, what it costs, and the Lean tab's one-tap fix already drafted (a deny rule for a lockfile or build output, a CLAUDE.md line for a file it keeps opening), diff and all. Apply to this project asks in the confirm window and Undo puts the file back; Not this one rests the file for a week; Never for this file is kept for good. A card nobody answers folds into one line when the reply comes.

### Changed
- **The fresh-tab offer is a line in the conversation.** Where the topic turns in a well-filled conversation, a dashed "New topic · 71% full" line is drawn in the feed, with the offer on it: what each message carries here, what a fresh tab would carry, the summary Shellby wrote there to edit, and Start fresh from here or Stay in this one. Your message waits under the line until you pick. Stay sends it here and leaves the line, so you can come back to it. Only one of these cards shows at a time, and the line comes before the model card.
