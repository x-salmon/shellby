### New
- **What a big run will cost, before it starts.** With Ultracode on, or when a message asks for several helpers at once, the box says what runs like that have taken of your 5-hour window here (the middle of your past runs, as a range), where you'd end up and when the window resets. A workflow's Run button says the same for that workflow first; one more tap runs it. Nothing to go by yet gets a rough guess, labelled as one. If it would likely run past your limit, Shellby says so and offers to run it after the reset instead. Nothing is ever blocked.
- **A fresh tab with Shellby's own summary.** When a conversation is well filled and what you're typing looks like a new topic, Shellby offers a new tab that starts with a summary he writes himself: the title, the files changed, the commits, the to-dos still open and the last few things you asked. No tokens spent writing it, you can edit it first, your message goes right after it, and the old conversation stays as it was. It says how many tokens every message would save. Offered once per conversation; the context chip's menu brings it back any time.
