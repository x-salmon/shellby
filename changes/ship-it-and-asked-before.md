### New
- **Ship it: a copy's work to a pull request in one go.** From the copy's menu, Ctrl+K or the review inbox (P), he runs the tests in the copy, commits what's left, looks the commits over for secrets, pushes the branch and opens a pull request into the branch the copy came from. The pull request is written from the conversation: its title, Claude's last reply (with anything that looks like a secret left out), the commits, the files and how the tests went. If the tests fail, nothing is pushed, and you can ship it anyway or ask him to fix them. "Ship it as a draft" opens a draft. Shipping again from the same copy pushes the new work to the same pull request, and a note in the conversation links to it.
- **"You've asked this before."** While you type a new task, Shellby looks through this project's History for a conversation that asked much the same. If it finds one, a quiet tip above the box offers to bring that conversation in as context, or open it, before Claude works it all out again. It's worked out on this PC and costs no usage. Turn it off in Settings → General.
